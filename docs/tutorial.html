Module 1: Principles, Legality & Recon Scope
FOUNDATIONS
Passive Reconnaissance (OSINT)
COVERT

Passive reconnaissance interacts strictly with third-party search engine index caches (Google, GitHub, Shodan). The target organization receives zero network packets from the auditor's IP address, eliminating disruption and IDS alert triggers.

  • Zero target telemetry generated
  • Surfaces historical and cached exposures
  • Fully compliant with passive engagement rules
Active Reconnaissance (Scanning)
DETECTABLE

Active reconnaissance sends packets directly to target servers (Nmap port scans, directory fuzzers, vulnerability scanners). Highly noisy in WAF, SIEM, and firewall access logs.

  • High risk of IP blocking / rate limits
  • Requires explicit written authorization
  • Can potentially disrupt fragile staging apps
Legal Framework & Safe Triage Rules
COMPLIANCE

Querying public search engines is lawful across all major jurisdictions (US CFAA, EU GDPR, French Code Pénal Art. 323-1). However, utilizing discovered credentials to log into private systems without explicit consent constitutes illegal unauthorized access.

The Golden Rule of Bug Bounty Dorking: If an AWS token or database dump is discovered, document the search query and exposed URL, obtain minimal non-destructive proof (e.g. aws sts get-caller-identity), and report immediately without downloading sensitive user records.

Module 4: Enterprise Defensive Remediation
HARDENING
Nginx Web Server Hardening
NGINX

Deny HTTP access to dotfiles, version control metadata, and database backups:

# Block hidden dotfiles (.env, .git, etc.) location ~ /\.(?!well-known) { deny all; return 404; } # Block database dumps and state files location ~* \.(sql|bak|dump|sqlite|tfstate)$ { deny all; return 404; }
Search Header Control (X-Robots-Tag)
NOINDEX

Do NOT rely on robots.txt Disallow (which lists the paths publicly!). Use HTTP response headers:

# Send X-Robots-Tag on internal admin routes location /admin/ { add_header X-Robots-Tag "noindex, nofollow, noarchive" always; }
