[2026-08-19] — Update CLI Shortcut Alias from df to dfg to Prevent Unix Coreutils Collision

What changed:
- Changed default build symlink and CLI shortcut alias from 'df' to 'dfg' across Makefile, shell completions, README.md, and interactive tutorials.
- Updated shell autocompletion generator (Bash, Zsh, Fish) in internal/completion/completion.go to register both 'dorkforge' and 'dfg'.
- Cleaned up any existing 'bin/df' symlink on build.

Why:
- 'df' (disk free) is a standard POSIX / GNU coreutils command present on every Unix and Linux distribution. Aliasing or installing 'df' in PATH conflicts with standard system administration tooling. 'dfg' (DorkForGe) provides a collision-free, memorable shorthand.

Files affected:
- Makefile — Updated ALIAS_NAME to dfg and updated build/install targets
- internal/completion/completion.go — Registered dfg in Bash, Zsh, and Fish completion scripts
- README.md — Updated quickstart examples and installation paths
- docs/TUTORIAL_INTERACTIF.md — Updated hands-on lab commands
- docs/tutorial.html — Updated interactive terminal copy commands
- commit.txt — Updated release notes

Breaking changes:
- 'bin/df' symlink is replaced by 'bin/dfg'.
